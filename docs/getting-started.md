# 上手与全局

[文档目录](README.md) · [按主题拆开的详细说明](GUIDE.md) · [返回 README](../README.md)

她把什么接管了、编辑器怎么用、第一次该怎么配。

## 她是怎么工作的

三条**严格互斥**的路径：

| 路径 | 触发 | 谁说话 | 做什么 |
| --- | --- | --- | --- |
| **接管回复**（默认） | 消息走到大模型那一刻（被 @、或意图路由放行） | 本插件自己 | 自己调大模型拿到 `reasoning` + `actions`，执行动作并发送，然后 `stop_event()` 阻止主人格重复回复；她说不出话或模型出错时，**这一条保持安静**，只在日志页留一条「接管失败」记录 |
| **注入状态**（可选） | 同上（回复方式选成「仅注入状态」时） | AstrBot 主人格 | 只往 `system_prompt` 追加「她此刻在书房、很困、想起上次在这里说过的话」，并按区域裁剪可用工具 |
| **自主行为** | 日程到点、决策器判定、插话、工具动作的后续 | 本插件自己 | 走动、发呆、看书、做饭、搜索、主动搭话 |

如果消息根本没走到大模型（被别的插件用表情包回掉了、命中了指令等），本插件完全不介入。
三条路径互斥，所以不会出现"一次 @ 回两条消息"。

### 她是谁：人设从哪来

**默认沿用 AstrBot 的人格**：插件会问 AstrBot「这个会话用哪份人格」（`persona_manager` 按会话 / 配置文件解析）。
好处是你不用维护两份人设；代价是**它是按会话解析的**——换会话、改组、换代表会话之后，
插件问的就是另一个会话，她可能变成另一个人，甚至退回 AstrBot 的默认助理人格。

所以「全局设置 → 基础 → **她是谁（人设）**」给了一份插件自己的角色卡：

| 人设来源 | 行为 |
| --- | --- |
| 跟随 AstrBot（默认） | 老行为：按会话取 AstrBot 的人格 |
| 用下面这一份 | 固定用插件这份，**所有会话 / 会话组共用**，也不再随会话变动漂移；留空时自动回落到 AstrBot 那份 |
| AstrBot 那份 + 这一份 | AstrBot 打底、插件这份接在后面（她的设定更靠后、更"近"） |

角色卡写在世界配置里，所以**跟着预设一起走**（存预设 / 换预设都带着），
对话框里还有「从 AstrBot 导入当前人设」一键把手上那份抄进来。
同一个 section 里的「简易人设（给打杂模型）」是从**当前生效的人设**摘要出来的，也一起对上了。


## 网页编辑器

插件在 AstrBot WebUI 的插件详情页里提供「**虚拟世界编辑器**」。编辑器是**左侧导航**，按用途分三组：

- **观察**：控制台 / 事件 / 通讯录 / 记忆库 / 日志 / 调试
- **编辑**：地图 / 动作库 / 日程 / 会话
- **配置**：全局设置 / 预设

顶栏固定三样东西：当前页名、**全局会话选择器**（控制台、事件、记忆库、日志、调试都跟着它走）、
保存状态与「保存」按钮；最右边是**主题开关**（深色 / 浅色，点一下切换并**记住选择**，下次刷新还是这个主题）。
窄屏下左侧导航会收成图标条，再窄就横过来放在顶上。

- **控制台**：最上面是**人物面板**——名字首字头像、群名片，一行摘要写着
  「状态 ｜ 区域 · 地点 ｜ 正在做的事 ｜ 心情」，右上角有个「事件页 →」可以直接跳过去。
  下面分三小节——**时间与日程**（现在几点/什么时段、世界时间对照、下一条日程还有多久）、
  **正在进行**（当前动作进度条、计划进度、区域 · 地点、从这儿能走到哪）、
  **互动与运行**（最近活跃的人、**本会话**没回 / 已回多少行、她上一轮写的话题背景、决策意愿、本小时剩余额度、
  发送通道与模型通道状态：最近一次模型调用成功还是失败、发送失败后还剩多少秒冷却）；
  右栏是数值、当前计划（可读的步骤列表）、内心活动、最近一次推理草稿，最下面是**心情曲线**
  （6 小时 / 24 小时 / 3 天三档，画的是每个 tick 记下的一帧数值）；
  数值平时是彩色的条（绿→黄→橙表示离「该注意」还有多远，精力这类越高越好的反过来算），
  点「编辑数值」才变成滑杆；**群名片可以直接填**（都在页头，有保存按钮，改动会记一条日志）；
  刚有动作被跳过时状态卡上会直接显示为什么；推进 tick / 触发决策 / 打断 / 叫醒 四个按钮都在页头，
  她没在做事、没在睡觉时按钮会灰掉；「触发决策」是手动触发，不受评估间隔限制
- **事件**（独立一页）：页头能**直接投递一件事**（例如「出门忘了带伞」），她会当场遇上；
  左边是**现在这件事**——她选的每一幕、判定档位、结果和还差什么，
  未完结时可以「立即推进一幕」（不用等那个间隔）或「立刻完结」（她写一句收尾就翻过去）；
  右边是「**她的本事**」**能力值雷达图**（体力/智力/灵巧/心性，值变了会补间过去，不会一跳一跳的）；
  下面「最近的线索」一行一条，点开进**历史事件**弹窗：每条都能展开看每一幕到底发生了什么，
  状态标着进行中 / 等群友拿主意 / 挂着没演完 / 已完结。
  原始的事件流水（最近 60 条）搬到了**日志页底部**，收在「实时事件流」里
- **地图**：分**世界地图**（区域 + 跨区连线）和**区域地图**（地点 + 区域内连线）两层，左上角面包屑来回切；
  单击区域/地点是选中编辑（会高亮），**双击区域直接进入区域地图**；
  拖动摆位置、连线中点标出走过去要几个 tick；跨区连线在区域属性里编辑（两端各选一个地点 + tick + 是否双向），
  区域地图上会把这些通道标成出口；可以按会话查看位置，也可以一次显示所有会话分别在哪；
  区域属性里能「用大模型生成地点」、地点属性里能「用大模型生成动作」，生成结果先列在弹窗里让你改、勾选，确认后才写进配置
- **动作库**：右上角可以在**卡片 / 表格**两种视图之间切（表格按「动作 / 类别 / 范围 / 时长 / 工具 / 状态」排，
  动作多了用它核对更快；选哪个视图会记住）。卡片视图里每张卡左上角是**启用开关**
  （停用 = 她根本没有这个动作），右下角三个图标
  是复制 / 编辑 / 删除；点卡片从右侧滑出**编辑抽屉**（带保存键），按动作类型自动隐藏无关字段；
  分组可以自己写（下拉里是已有分组，也能填新的）、地点是多选、工具可以多选
  （参数只读展示每个工具自带的定义）、完成效果是
  「属性 + 增加/减少/设为/乘以 + 数值」的行编辑，**不需要手写 JSON**；
  左边是**分组菜单**（点一下只看这一组，再点「全部」回到全部）、页头还有搜索和「编辑 JSON」；
  装了扩展（独立安装的插件）时，菜单下半截会多出各扩展带来的动作，和原版动作分开列
- **日程**：星期是七个可选按钮，动作链按行编辑（选动作、选目标地点、填时长、填要说的话），触发条件同样是多选；
  动作下拉里会直接标出「（需先在书房）」这样的地点要求，缺移动时可以一键「↩ 先移动到X」，
  也可以打开日程的「自动先走过去」让插件自己补
- **会话**：白名单增删与启用/禁用、冷启动模式
- **预设**：把当前的地图 / 动作 / 世界设置 / 人设 / 日程 / 会话打包存成一份，随时切回来。
  「**新建默认预设**」用内置默认世界新建一份（不动当前配置）；应用时是**分块**的——
  勾中哪几块就替换哪几块，其它保持你现在这套：

  | 块 | 内容 |
  | --- | --- |
  | 地图 | 区域 / 地点 / 连线 |
  | 动作 | 动作定义（含生图动作、使用次数上限） |
  | 世界设置 | 作息、情绪、画像、事件、提示词预算… |
  | 她是谁 | 插件自己那份人设（见上文） |
  | 日程 | 日程表 |
  | 会话 | 白名单与会话组（**默认不勾**，勾了会把现在的换掉） |

  另外「同时清空所有会话状态」**默认不勾**：不勾就保留原会话的上下文（位置、数值、计划、群聊留档），
  只按勾中的块换配置；换了地图却没清状态时，插件会顺手把状态修一遍
  （站在已经不存在的地点 → 落到新地图的默认地点；计划 / 当前动作引用了不存在的动作或地点 → 丢掉并记一条日志）。
  应用前会**自动备份**当前配置（存进「改动历史」）。
- **改动历史**：预设页那个按钮。每次写配置之前都会先留一版（手动保存 / 应用预设 / 恢复默认 /
  日程自动回收…），写明来源与"相对上一版改了哪几块"。
  点一条看它跟**现在**的差别，可以**只挑某几块恢复**（例如只把人设恢复回去，地图不动）；
  恢复前的那一版同样会留档，所以"恢复"本身也能再恢复回来。只留最近 50 条，
  内容没变的不重复占位；早期那批 `before-apply-*.json` 也列出来，标成"旧版备份"且不参与滚动删除。
- **她 / 他 / ta（人设）**：标题跟着性别设置走。构成"这个人"的设置都在这一节：
  性别、Bot 名称、人设来源、角色卡、**声音样例**、**简易人设**。
  这一节还有两个按钮：
  - **优化人设…**：先体检（重复 / 缺维度 / 形容词没落地 / 矛盾 / 篇幅 / 不该有的 / 怪癖保护），
    再把改动列成「改：原文 → 改后」和「加（口头习惯）：…」，**你勾哪条才写哪条**；
    找不到原文的条目会跳过并报出来。写前自动留档。
  - **生成测评剧本…**：按角色卡写 20 轮考卷（场景 / 用户原话 / 看什么 / 禁忌），
    拿去跑不同模型盲选哪版更像她。**这份东西不会进提示词**。
  - **声音样例**：页面上只放「已采用」——**只有这一份会进提示词**，每条都能点 ✎ 改文案 / 换场景 /
    加动作说明。候选攒在单独的弹窗里：点「挑选候选…」勾选要采用的、✕ 从候选里删；
    候选有两个来源——「生成候选」让内容生成模型按场景说几句（每个场景三条不同走法），
    「从近期聊天挑」翻她近期说过、而且**后面有人接话**的句子（连当时对方说的那句一起列出来）。
    候选池最多 80 条。
- **记忆库**：按节点/类型/作用域筛选、统计；编辑与新增是**弹窗表单**
  （内容 / 类型 / 作用域 / 绑定地点 / 权重 / 情绪标签），删除与恢复默认都有确认框；
  每行可勾选，支持「全选 / 删除选中 / 清空本会话」
- **日志**：把她的每一次决定与动作按时间排成一条线——用户说了什么、她决定做什么（决策原因 / 模型原话 /
  推理草稿）、真正执行了什么、说了什么、哪些动作被跳过以及为什么。支持按会话、类型、关键词筛选；
  点任意一条，右侧先用**人话**讲清这件事（类型、时刻、编号 + 说明 + 结构化字段），
  要较真时再展开下面的「原始数据（JSON）」；也能勾选批量删除 / 清空本会话、一键导出 JSON。
  页面最下面还收着一条「**实时事件流**（最近 60 条原始记录）」，平时折叠着，点开才展开
  几个群 / 私聊编成一个会话组时，这一册日志是**共用的**：每一条会标出这件事发生在哪个会话
  （行尾的「〔在 私聊 2692047521「备注」〕」），私聊里说的话不会看起来像群里说的
- **全局设置**：横向分成六个用途标签（基础 / 状态与外观 / 说话与决策 / 世界与事件 /
  记忆与上下文 / 调试与安全），顶上有搜索框，能直接按字段名跳到对应标签。
  字段全中文命名、每项都有悬停说明；**低频但一个都不能少的字段收在每节的「高级设置（n 项）」里**
  （默认收起，点开才展开），所以第一眼看到的是真正要改的东西。
  高级用户仍可在最底部直接编辑 world.json
- **调试**：预览注入内容与自主提示词、查看已注册工具、备份配置。
  预览输出不再是一整块文本：上面是**状态槽**和本轮抽到的**声音样例**，
  下面是按标题切好的**分段全文**（顶部一排小标签可以直接跳到某一段，「全部展开 / 全部收起」一键切换，
  「复制全文」把整份提示词复制走）——几千字的提示词也能一眼看出哪一段没进去

编辑器默认复用 AstrBot WebUI 自身的登录鉴权。如果你把 WebUI 暴露在公网、想要二次保护，
可以在插件配置里填 `web_password`（或在编辑器里设置密码），之后编辑器会要求单独登录。


## 设置向导与手感滑块

第一次打开编辑器会自动弹一遍向导，六步：

1. **她在哪儿生活**：会话白名单（只有加进来的群 / 私聊才会启用本插件）。
2. **她是谁**：角色卡、简易人设、性别与称呼。
3. **模型检查**：看看七个模型槽位有没有漏配。
4. **手感**：下面这 8 个滑块。
5. **记忆与画像**：画像开关、睡眠整理的节奏。
6. **让她说话像自己**：简易人设 + 声音样例（可以跳过）。

想再走一遍：全局设置 → 基础 → 最上面的**「重新运行设置向导…」**。

### 8 个滑块

| 滑块 | 它管的是 |
| --- | --- |
| 主动说话频率 | 她多久自己冒一次头（被叫到时的回话不算） |
| 群聊活跃度 | 群里热闹时她插话的意愿 |
| 私聊粘人程度 | 想你的速度、主动找你的次数、有多在意被冷落 |
| 一次说几句 | 单次回复的长度上限，以及"说话太密"的判定 |
| 情绪起伏 | 多容易被逗乐、多容易被惹到，情绪回得多快 |
| 生活丰富度 | 她一个人待着时遇上事的多少 |
| 任性度 | 多凭性子来：多少概率交给模型自由发挥、情绪上头多久、随手拍不拍照、题材重不重样 |
| 记忆勤奋度 | 记你记得多细、整理得多勤 |

三条规矩（测试里钉住了）：

- **每个滑块管的字段互不重叠**——重叠了就会出现"拖完 A 再拖 B，A 就白调了"；
- **中间那档 = 内置默认值**——老用户拖回中间等于没改，不会一拖就变样；
- **只写它管的那几个字段**，别的一律不碰。

展开滑块的「会改哪些参数」，能看到每一档具体改哪几个数字、这些数字是什么意思；
你之后手动改过其中某一项，滑块旁会标「已手动调整」。

更细的参数（想念、主动问、好感度回落、睡眠整理节奏）在**全局设置 → 记忆与上下文**里，
不在滑块上——滑块只负责"一眼能懂的那几个方向"。


## 插件配置

`_conf_schema.json` 只放开关和接口，复杂配置都在网页编辑器里。

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | true | 插件总开关 |
| `web_enabled` | true | 是否显示网页编辑器 |
| `llm_provider_id` | 空 | 插件自己发起的调用用哪个 Provider；留空用会话默认。分工见下一节 |
| `helper_provider_id` | 空 | **辅助模型**：把「她想干什么」翻译成工具参数。建议填便宜、快、能稳定输出 JSON 的模型；留空则复用 `llm_provider_id` |
| `vision_provider_id` | 空 | **图片转述模型**：必须是支持图片输入的多模态 Provider。**留空表示不转述，直接把图片交给多模态主模型**（上限见「全局设置 → 上下文」） |
| `context_provider_id` | 空 | **上下文压缩模型**：只在「全局设置 → 上下文 → 留档超了怎么办 = 压成摘要」时才会被调用；留空复用 `llm_provider_id` |
| `creator_provider_id` | 空 | **内容生成模型**：只在编辑器里点「生成动作 / 生成地点」时写草稿，运行时完全不调用；留空复用 `llm_provider_id` |
| `tick_interval` | 60 | 世界时钟步长（秒）。`world_time` 以 tick 计数，动作/移动耗时都以 tick 为单位 |
| `decider_interval` | 300 | 自主决策评估间隔（秒） |
| `web_password` | 空 | 编辑器二次访问密码，留空表示复用 WebUI 鉴权 |
| `debug` | false | 把注入内容、接管详情、动作校验结果写进后台日志 |
| `reply_hook_bridge` | true | 把接管的流程补进 AstrBot 的钩子链：回复过「LLM 响应后 / 发送前」，流程过「等模型 / 用工具 / 用完工具 / 发完消息」。让「好感度」这类靠解析回复标记、以及靠钩子贴表情的插件照常生效。某个插件在钩子里会重复发消息时可以关掉 |
| `log_level` | INFO | 插件日志级别 |

数据（世界配置、日程、会话、记忆数据库）统一放在 AstrBot 的
`data/plugin_data/astrbot_plugin_virtual_world/` 下，跟着 AstrBot 的数据目录走。
如果要放到别处（例如挂载卷），设置环境变量 `VIRTUAL_WORLD_DATA_DIR` 指向目标目录即可。


## 默认世界

五个区域、二十一个地点，连成一张带跨区门户的地图（每条连线都标了走过去的 tick 数）：

| 区域 | 地点 | 这一带来了能做什么 |
| --- | --- | --- |
| 家中 | 卧室 / 书房 / 窗边 / 吧台 / 厨房 / 客厅 / 浴室 | 睡觉、小睡、看书、上网、发呆、倒茶、做饭、追剧、瘫沙发、洗澡、泡澡、照镜子 |
| 商业街 | 街口 / 商场 / 小吃街 | 逛店、吃点小吃 |
| 学校 | 校门口 / 教室 / 图书馆 / 操场 / 天台 | 旁听一节课、跑两圈、看书、查资料、发呆、看天 |
| 公园 | 公园大门 / 长椅 / 湖边 | 散步、喂猫/鸽子、发呆 |
| 海边 | 海滨步道 / 沙滩 / 礁石 | 吹海风、踩水、捡贝壳 |

跨区走的是「区域内 → 门户 → 目标区域」，门户在世界地图上是一条线（客厅↔街口、客厅↔公园大门、
街口↔校门口、街口↔公园大门、公园大门↔海滨步道）。从卧室出发：客厅 1 分钟、街口 4 分钟、
公园 5 分钟、海边 8 分钟、图书馆 9 分钟、天台 11 分钟——出门一趟是有代价的，不会一分钟就跑到海边。

默认日程：

- `08:30` 走到大厅伸个懒腰
- `18:00` 去厨房做饭，做完会把这道菜讲给大家听
- `23:30` 回卧室睡觉（8 小时）

睡觉和小睡是两件事，说明里写清了使用场合：**睡觉**是睡一整晚（约 8 小时，夜里/凌晨或实在撑不住时用，
只能在卧室），**小睡**是白天犯困时打的盹（10~60 分钟，卧室或大厅都行）。模型能不能挑对，取决于
提示词里有没有「现在是几点、什么时候段」——所以运行时状态的第一行就是当前日期时间。

规则决策也是同一条规矩：**精力低于 0.25 时，夜里去睡整觉，白天只是先小睡一会儿**（白天一睡八小时，
醒来正好是半夜，日子直接过乱）。小睡睡多久不是写死的——按小睡动作自己配的「每持续 1 分钟恢复多少精力」
反推，睡到大约缓过来为止，再卡在动作声明的 10~60 分钟范围内；你把小睡的恢复速度调高，它就会自动睡短一点。
「极端保护」在白天也不再直接甩 8 小时：透支时先眯到小睡的上限。

「几点到几点算夜里」在「世界与事件 → 作息与夜晚」里配（默认 23:00–07:00）。同一节还管三件事：

- **非夜晚时段提示词里不提供「睡觉」**，模型写出来也会被忽略（想白天也能睡整觉就关掉这条限制）；
- **夜里醒着要付熬夜代价**：精力衰减 ×「熬夜时精力衰减倍数」（默认 1.5）；打盹、睡整觉都不算熬夜；
- 为事件推迟睡觉时同样按这个倍数扣，两处**取较大值、不叠加**（免得又乘又乘）。

默认动作按用途分四类：

| 类别 | 动作 | 特点 |
| --- | --- | --- |
| **互动类** | 亲昵向：抱抱、亲亲、摸摸头、笑、挥手、倒茶提醒喝水、**戳一戳**、点头、摇头、鼓掌、歪头、眨眼、击掌、拍肩、递纸巾、分你一半、揉乱头发、扯衣角、撞肩膀、捏鼻子、冰手偷袭、咬肩膀、咬手腕、牵手、靠肩膀、蹭蹭、捏脸、闭上眼、亲额头、擦眼泪、揉肩、披外套、十指相扣、钻怀里、投喂、接吻、耳边说 | 模板文案 + 数值联动，零 token。文案里用 `{bot}`/`{user}`，例如「（{bot}抱了你一下）」，会替换成你在全局设置里填的 Bot 名称；「戳一戳」会真的发 QQ 的戳一戳（群里走消息段，**私聊走 `friend_poke`**；协议端不支持时退回文案）。这些动作按亲密度铺开，效果逐档递增，说明默认简写（只写 `- id（名字）`），可以在动作编辑器里改回"带说明" |
| **互动类** | 上面这些是一整套：**够亲密才做得出来**，提示词里会写明"动作按距离分档"（打招呼 → 打闹 → 亲昵 → 最亲密），越界的一律不做也不提 | 想加自己的互动动作照抄一个改模板即可；`desc_mode` 选「只写名字」就不会往提示词里塞说明 |
| **表达类** | 说话、分享、哼歌、听你说、打气 | 让大模型按人设说一句 |
| **生活类** | 睡觉、小睡、发呆、看书、做饭、洗澡、泡澡、照镜子、追剧、瘫在沙发上、逛店、吃点小吃、旁听一节课、跑两圈、散步、喂猫/鸽子、吹海风、踩水、捡贝壳 | 时长由大模型在区间内决定，效果按"每持续 1 分钟"结算；看书、做饭、上课、跑完这类做完还会接一段分享 |

「时长由大模型决定」的动作（`duration_mode = llm`）会在动作那一行标出范围
（例如「时长由你定：10 分钟 ~ 1 小时」），并要求她把结果写进 `duration`（秒）。
她只把时长说在 intent 或台词里（「小睡三小时」）而忘了填 `duration` 时，
引擎会从她自己的话里读一遍，再按动作配的最短 / 最长夹住——不会一律按最短睡。
| **工具类** | 上网搜索、查天气 | 内置动作，默认绑 `web_search` / `get_weather`，本机没装就自动换成本机装好的那个（搜索类、天气类各带一串备选）；一个都没装就跳过这一步并在日志里写明原因，编辑器也会在控制台页和动作库页提示 |
