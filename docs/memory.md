# 记忆与通讯录

[文档目录](README.md) · [按主题拆开的详细说明](GUIDE.md) · [返回 README](../README.md)

她记得谁、记得什么，以及画像与记忆存在哪。

## 通讯录：她认识的人

记忆回答"发生过什么"，**通讯录**回答"这个人是谁、我跟他什么关系、我该怎么对他"。
编辑器里的「通讯录」页分两块：**好友**（一个人一份画像）和**她能说话的地方**（会话 / 群）。

每份画像里有：

- **基本**：昵称 / 别名（改过名会留历史）、QQ 号、各群的群名片、认识多久、聊过多少句；
- **称呼**：他让她怎么称呼自己（只有他明确说"叫我 X"才会改，黑名单里的直接拒绝）、她怎么称呼他；
- **好感度**：-100 ~ 100，带变化日志；只写进提示词由她自己判断做什么，**不做硬门槛**；
- **关系**：可同时有多个（主人 + 男友并存），带确立日期；唯一关系（男友 / 主人 / 闺蜜）全组只有一个，
  别人再声明只会记成"他自称"，她可以认也可以不认；解除后保留成"曾经"。
  **同类关系（群友 / 朋友 / 闺蜜 / 男友 / 女友）在同一个人身上只留一条**：她判断成新的那条之后，
  旧的那条自动变成"曾经"（带起止日期，提示词里就能写成"你们从朋友变成男友了"）。
  这一类**升降都算**——她也可以自己退回朋友、甚至翻脸，只要她判断得出来；
- **事实**：喜好 / 厌恶 / 习惯 / 基本信息 / 约定 / 近况…每条都带**他说的原话**做证据，
  同类会去重、正反（喜欢辣 / 不喜欢辣）自动替换；可以置顶、删除；
- **缩略版**：睡眠整理生成的一句话印象，给"群里其他人"那一行用。

**提示词里给她什么**（信息给全，但只给会参与这一轮的人）：

```
# 你在跟谁说话
- 不相疑（QQ 2692047521）——主人（2026-09-17 起）
- 认识 6 天，聊过 214 句；你对他：亲近（78/100）
- 他让你叫他「蓝蓝」；你叫他「小笨蛋」
- 他喜欢：猫、异环、辣｜他不喜欢：苦瓜
- 你们的约定：周二晚一起看片
- 你跟他很亲近：会撒娇、会抱抱、会分享日常自拍，夜里他找你也会回
- 现在还不能：拍腿的照片
- 这些是你早就知道的事：不用问、不用复述，合适的时候自然带出来

# 群里还有谁（只当背景）
- 小明（朋友）：爱开玩笑、常聊工作
```

**生效档位 = 好感度达到的级别，先被关系的「最低档」抬起、再被「最高档」压下**。
每一档的称呼、这一档还不能做的动作、给模型的提示词文本都在「全局设置」里配（分级表 + 关系表）；
关系表里每行两个档位是这么用的：

- **最低档**：关系本身就是一种态度——绑成男友之后，哪怕好感还没养起来也能抱抱，
  否则提示词里会同时出现"他是你男友"和"你们还不熟，别贴贴"，自相矛盾；
- **最高档**：普通关系聊再久也上不去，群友封在"熟人"，只有关系升级才放宽。

最低档**只在好感不为负时生效**：好感掉到负数就是「冷淡 / 敌意」——她可以对男友生气，
不会因为"关系是男友"被翻回亲近。

（老配置里没有最低档，读进来时会按关系名从内置表补一份；名字对不上的自定义关系保持 0，不瞎猜。）

这一档的 `deny`（禁止的动作）会写进提示词里的「**这一档还不能做**：抱抱、亲亲…」，并明确
"不做，也不提；他开口要就用你自己的语气拒掉或岔开"。另外还会补一句"再熟一点才到「X」那一档"，
只讲当前档和上面那一档，不把四级阶梯全铺给她。**亲密度靠模型自己克制**，
不把动作从列表里摘掉——群里常常同时有亲疏不同的人，一刀切摘掉会连最亲的那个人也用不了。

**「想念」是独立的一条线**：群里再热闹也不算有人陪她（热闹只降无聊），
只有有人**直接跟她说话**才会清掉对他的想念；攒够了提示词里会写「你有点想他 / 她（上次跟他说话是 3 天前）」，
她可以主动私聊去找那个人。

「**见过**」和「**聊过**」是分开记的两件事：他只在群里露个面（哪怕一直在刷屏）只算"见过"，
只有他直接跟她说话（@她、私聊她）才算"聊过"——想念只认后者。所以一个人天天在群里闲聊、
却从没找过她，她照样会惦记他，提示词里还会补一句"他 10 分钟前在群里露过面"，
让她知道人还在，只是没来找她。

想念的细节（都在「全局设置 → 记忆与上下文 → 用户画像」里配）：

- **越亲近越想**：每分钟涨幅 = `miss_growth_per_min` ×（0.5 + 好感/100 + 0.4×关系条数-1）
  ×（1 + `miss_loneliness_weight` × 孤独感）。
  群友那种关系几乎不涨；主人 + 男友、好感 60 的人涨得比陌生人快三倍。
- **越孤独越想**：同一段没人找她的时间，孤独感 0 时按原速涨、孤独满时按
  `1 + miss_loneliness_weight`（默认 1.8）倍涨——刚聊得热乎时不太会惦记谁，
  越没人陪越容易想起某个具体的人。
- **不是固定节拍**：每次他跟她说完话（或者她刚主动找过他）之后，想念会先归零，
  然后在 `miss_cooldown_min_minutes`（默认 45）到 `miss_cooldown_max_minutes`（默认 240）
  之间**随机**挑一段时间"不开闸"；这段时间过了才会重新慢慢涨。所以有时一下午就想他，
  有时一整天都没想起来，不会规律地每隔固定时长去打扰同一个人。
- **不喜欢的不惦记**：挂过「讨厌的人 / 敌人」、或者好感是负的，想念直接清零，不再累积。
- **想他会真的去找他**（`miss_push_enabled`，默认开）：想念超过 `miss_push_threshold`（默认 0.85）
  时，她会**主动去找他一次**——**在哪说由她自己决定**：想私密、想撒娇就发私聊，想让别人都看到
  你们关系好就发群里（提示词里把她能说话的地方都摆出来让她挑）。
  一次软推之后这个人的想念清零，每天最多软推 `miss_push_daily_max`（默认 2）次。
- **主动找人的额度**：分级表里每一级都有「**每天最多主动找他几次**」——陌生人 / 客气是 0
  （她不会主动去逗不熟的人），熟人 1、朋友 2、亲近 3、特别的人 4。
  这条**真的会生效**：她自己主动对某人做事（抱抱、戳一戳这类）要花这个额度，用完了就跳过并写日志；
  **你自己排的日程不受它限制**（那是你安排的，不算她临时起意）。

### 好感度是怎么动的

好感度是"她对这个人的感觉"，跟**效价**（她此刻的心情好坏）是两套数。它有四条来源：

| 来源 | 什么时候 | 默认幅度 | 限流 |
| --- | --- | --- | --- |
| **混脸熟** | 他**露个面**就加（不用 @ 她） | 每次 +0.05 | 同一人 10 分钟只算一次；每人每天最多 +2 |
| **她自己判断** | 每轮回复里的 `affinity_delta`（聊得走心/被冒犯时她才会写） | -1 ~ 1 之间 | 每轮最多 ±3；每人每天最多 +10 / -10 |
| **当场记住 / 睡眠整理** | 内置动作「记住」、睡着之后的整理 | ±几 | 她自己的判断，带理由 |
| **慢慢回落** | 每天朝 0 淡一点（长期不理就慢慢忘） | 0.2 / 天 | 每个会话组一天只结算一次 |

这几条都是**按人**算的，而且加与减各有额度：所以私聊连着刷、或者被反复 @ **都不会一路涨满**；
反过来，聊得再久也不会因为"说了很多句"就自动变成最亲近的人——真正拉近距离的还是内容。
数值都在「全局设置 → 记忆与上下文 → 用户画像」里配（`presence_affinity` 设 0 = 关掉混脸熟，
`affinity_decay_per_day` 设 0 = 不回落）。

**好感度给档位，关系给上下限**：一共七级（敌意 / 冷淡 / 客气 / 熟人 / 朋友 / 亲近 / 特别的人，
门槛是 -40 / -10 / 10 / 30 / 55 / 80）。关系类型各自带一个区间，默认数据是：

| 关系 | 最低档 | 最高档 |
| --- | --- | --- |
| 陌生人 | 2 客气 | 2 客气 |
| 群友 | 2 客气 | 3 熟人 |
| 朋友 | 3 熟人 | 4 朋友 |
| 闺蜜 / 主人 | 4 朋友 | 5 亲近 |
| 男友 / 女友 | 5 亲近 | 6 特别的人 |
| 家人 | 4 朋友 | 6 特别的人 |
| 讨厌的人 | 0 敌意 | 1 冷淡 |
| 敌人 | 0 敌意 | 0 敌意 |

所以「绑了男友但好感才 20」是**亲近**（能抱抱，还到不了"特别的人"），
而「群友就算好感拉满」也只能到**熟人**——普通关系不能亲亲这条依然成立。
通讯录详情页会把关系、生效档位和"这一档还不能做"都写出来，就是为了看清这一点。

**绑上关系的那一刻，好感会被抬到这一档的最低值**，而且只往上抬：
好感 0 的人被认成男友 → 直接变成 55（亲近档的下边界）；好感本来就 80 的人，
绑什么关系都不动。这样才能保证"关系"不是一句空话——认了就是认了，
不会出现"绑了男友却还按陌生人的好感对待"。抬起来的那一下会记一条好感变化
（来源写"绑上关系"），在通讯录的最近变化里看得见。

这条下限**只对非负的好感生效**：好感掉成负数时关系再亲也没用，
该冷淡还是冷淡（男友惹毛她了照样不给抱）。

### 她自己动手改画像：内置动作「记住」

事实、关系、好感度**不是只在睡下之后才更新**：她有一个内置动作「**记住**」，
当场就能把这些写进通讯录（和睡眠整理共用同一套写入与校验）：

| 参数 | 说明 |
| --- | --- |
| `user` | 记的是谁（QQ 号）。**只认她真的见过的人**，编出来的号码一律不写 |
| `text` | 一句话说清是什么事 |
| `evidence` | **他的原话**（必填）。没带原话的事实 / 关系一律不记 |
| `kind` | 喜好 / 厌恶 / 习惯 / 基本信息 / 关系 / 约定 / 近况 |
| `bond` | 可选：顺手改关系（朋友 / 闺蜜 / 主人 / 男友 / 讨厌的人…），冲突按关系表策略处理 |
| `affinity_delta` | 可选：顺手调好感度（-10~10） |

写法就是普通动作的参数（`{"type":"remember","params":{…}}`），写完不用再说一句——
想顺口提一句就另外写一个 `say`。
「**回想**」也接上了这条：翻出来的旧事里如果关于某个人的信息、或者你们的关系**已经变了**
（称呼变了、喜好变了、约定作废了、亲疏变了），续说那一轮会提示她用 `remember` 把新情况改掉。

**「缩略版画像」是画像速写，不是事件流水**：它只写"这个人是谁、怎么说话、喜欢什么、你们什么关系"
这类稳定特征，**不写他最近遇到的事**（那类事属于「事实 → 近况」或者记忆）。整理模型偶尔会把它写成
"抽卡一发出了角色"这种近况——提示词里已经写明不许这么写；通讯录详情页顶部那一行就是它。

**页面别越用越长**：通讯录详情页现在先给一行「概况」（认识几天、聊过几句、群名片、关系上限），
历史关系默认折起来，事实默认只显示置顶 + 最近 8 条（其余点「还有 N 条」展开），
好感日志只显示最近 8 次并标出是谁改的（混脸熟 / 她自己判断 / 慢慢回落 / 睡眠整理 / 当场记住）。

### 她记着的账（记仇）

关系表那几条是**长期定性**（讨厌的人 / 敌人，由你配）；记仇是**事件性的、可逆的**：
他做了一件让她气着的事（答应的事又没做、放鸽子、当众让她下不来台、骗了她），她记一笔。

记的账会让她**对这一档冷一档**——不是改关系、也不是扣好感数值，而是把**生效档位**压下去一档
（默认 1 档，可配）：原本能抱抱的"亲近"档，气着的时候退回"朋友"档该有的规矩。
而且这条账**只在跟他说话时**才拿出来，别人面前一个字不提。

几条刻意卡紧的闸：

| 闸 | 默认 | 为什么 |
| --- | --- | --- |
| 同一个人 | 最多 1 笔 | 不叠加：这件事比那件事更气人就换掉 |
| 同时最多几笔 | 2 笔 | 整个会话组算一份，不然她会变成记仇机器 |
| 一天最多记几笔新的 | 1 笔 | 天天记仇的人不可爱 |
| 一笔记多久 | 7 天 | 到期自己淡掉，并写进记忆（「气过一阵就算了」） |

**怎么消**：他道歉 / 补上了 / 解释清楚了 → 那笔账划掉，并留一条她自己的记忆（「跟他算清了一笔账」）；
通讯录里那个人详情页有一块「她记着的账」，可以手动记一笔、点「算了」、或者直接删掉。

提示词里一次最多带 2 条（回话时只有当前这个人的那一条，因为一人只留一笔）。

### 她自己答应过的事

跟「还没聊完的」正好对称：那份记的是**别人的**事，这份记的是**她自己的**事——
答应给他看照片、想做顿饭。她会在合适的时机顺手做掉，或者顺口提一句
（上次说要给你看的），做完自己划掉。

默认同时最多 2 件、一件记 3 天，超期就丢掉：要么早做完了，要么她其实不在意——
两种都说明不用再挂着。

### 睡眠记忆整理

她睡着之后会整理这段经历——就像人睡着时海马把白天的经历搬进长期记忆。节奏是
**一段睡眠最多两次**：睡下 **20 分钟**第一次（把白天的经历消化掉），睡满 **5 小时**补一次
（第一次整理发生在睡下 20 分钟，睡前最后聊的那几句这时才进去）；**不是每 20 分钟轮一遍**。
两个时间点都能在「全局设置 → 记忆与上下文 → 用户画像」里改（补一次填 0 = 只整理一次）。

整理分三步：

1. **消化**：这段时间的原始聊天（带时间、谁说的、谁在场）+ 现有记忆 + 画像现状 → 要点、事实、关系、缩略版；
2. **重组**：同一个人的同一件事合并、被确认过的旧记忆改写、值得记住的事排下次回访（1 / 3 / 7 / 30 天）；
3. **遗忘**：只**折叠**（正文换成一句要点，原话进「当时：…」留着），**不删除**。

相关开关与设置：

- 模型：插件配置里的「**睡眠整理模型**」（留空跟随打杂模型）；一天只跑一两次，token 多一点没关系，
  但别用太小的模型（它要判断关系、写缩略版）；
- 开关：「全局设置 → 用户画像」里的 **用户画像** 与 **睡眠整理**（默认都开）；
- 手动跑一次：通讯录页右上角「现在整理一次」；
- **先看再决定**：旁边那个「**预览整理**」会照常组装输入、调模型、解析，但**一个字都不写库**，
  把「喂进去的提示词 + 模型原话 + 解析结果」都摆出来——整理质量不对时一眼能看出来。
  每次整理的模型原话也会写进日志（「整理」那条）。
- 两道防编造：没带"他的原话"（evidence）的事实和关系一律不记；一次最多记 8 条事实、4 条关系；
- **小睡**只做轻整理：要点化 + 刷新缩略版 + **一条梦**（不碰关系、事实与遗忘）；
  梦是低权重记忆，进「想起」那一段、不进画像，第二天她可能顺口提一句。

### 回想与「忽然想起」

- 关于过去的事、关于某个人的事，她会先看记忆与画像；想不起来就用「回想」去翻，**不许编**；
- 回忆可以点名："回想一下关于主人的事" 会优先挑跟他有关的那几条（记忆带参与者）；
- 被想起来的记忆会**加强**一点（召回 = 提取练习），不会再因为"想起来太多次"而被永久降权；
- 到点的回访会写成提示词里的「**你忽然想起 …**」（每天最多 5 次、同一个人每天最多 2 次、
  同一件事 7 天内不重复提）：想提就顺口提一句，也可以顺着这条主动去找那个人。

### 合并转发的聊天记录

群里转进来一长串聊天记录（QQ 的「合并转发」）时，原文可能几十条：原样带进上下文会把别的挤掉，
只留一句「这是一条转发的聊天记录」又等于没读。开「合并转发压成摘要」
（全局设置 → 图片转述）之后，它会被交给**看图模型**读一遍——文字和转发里的图一起看，
压成一段摘要（默认最多 300 字）替换进聊天记录，她看到的是"这件事是什么"，而不是一个占位符。

- 只在她**要处理这条消息**时（@ 了她 / 私聊 / 唤醒）才读；群里别人转的东西不会白花一次调用；
- 摘要是**按内容缓存**的（同一条转发再被转一次直接复用），跟着「同一张图只识别一次」那套开关与上限走；
- 提示词和字数上限都能改，留空用内置默认；
- 关掉这个开关、或者没配看图模型时保持原样：记录里只落一句「这是一条转发的聊天记录」。


## 状态、记忆与存储

- `state.db`（SQLite，WAL）：每会话 `WorldState`、场景记忆、关系、事件日志、键值、日程触发记录
- `world.json` / `schedules.json` / `sessions.json`：可读可改，编辑器直接写这些文件
- 记忆按作用域存储（group / persona / group_persona / global / node），召回时按配置过滤并打分
  （权重 × 用户匹配 × 节点匹配 × 时间衰减 × 召回惩罚）
- 记忆冲突策略：`newest`（默认）/ `highest_weight` / `skip_conflict`
- 记忆衰减：30 天半衰期（只在**召回打分**时打折，不会因为年纪大而被删掉）；
  条数上限是每个「会话 + 人格」500 条，超了才按权重从低到高淘汰
- **权重不是写死的**：写入时会按「这段经历的情绪有多强」加成——
  显式情绪标签、mood、正文里的强情绪词（生气 / 吵架 / 心疼 / 别走…）取最大值，
  再加心潮 × 0.15。所以吵架、表白这类记忆比"今天天气不错"更容易被想起来。

### 对话是怎么变成记忆的

**主动回想（内置动作「回想」）**：她可以自己想回忆点什么——按主题（「想想在厨房做饭的事」）、
按地点（「回忆一下书房里的事」，只看那个地点）、或者按区域（「回忆公园里的事」，翻该区域下所有地点）。
不写地点就是跨地点找，当前所在地点只是更容易被想起来。回想是瞬时动作，也不需要她在同一次输出里再写别的动作：
插件翻完记忆会**带着回忆到的内容再问她一次**，那时她才开口；什么都想不起来时会照实说，不会编。
刚被想起过的记忆会有一段时间"轻一点"（默认 2 小时窗口、最多打对折，可调），出了窗口自动恢复。
「调试输出」里勾上「回想开始 / 回想完成」就能看到她想回忆什么、翻到了什么。

逐条存「某某说了什么」几乎没有信息量（同一个人连说五句就是五条），所以对话是**攒成片段再总结**的：
聊天内容先进一个待总结的缓冲，等到**触发点**才让大模型把它压成一句以她的视角写的记忆，
例如「小明今天加班到很晚，说自己快撑不住了，我有点心疼」。

| 触发点 | 说明 |
| --- | --- |
| 这段聊完了 | 距最后一条对话超过「聊完多久算一段」（默认 30 分钟） |
| 攒够条数 | 同一段对话达到「攒够多少条总结一次」（默认 10 条，含她自己说的话） |
| 她换了地点 | 走开时把刚才在那个地点聊的内容总结掉，记忆挂在**原来那个地点**上，下次回到那里能想起来 |

只有她自己说话（自言自语、一个人做事）时，总结会以「我做了什么、当时怎么想」来写，
不会去追问"对方是谁"；万一模型还是写出这种反问句，这句话会被丢掉、改用她自己的原话兜底。

具体调用时机是每个 tick 检查一次（不占会话锁，不会拖慢消息回复）。这三个开关和长度上限都在
「全局设置 → 记忆」里；把「把对话总结成记忆」关掉，聊天内容就完全不进记忆。

两个细节：

- 模型在回复 JSON 里顺手给的 `memory` 字段**只是写记忆时的提示**（会一起喂给总结的那次调用），
  不再单独存成一条；
- 模型不可用时退化成一行摘录（「小明说「我今天加班到现在才下班」」），而不是什么都不记。
