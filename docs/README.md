# 文档目录

[返回 README](../README.md) · [详细说明 GUIDE](GUIDE.md) · [设计理念](design-philosophy.md) · [更新日志](../CHANGELOG.md)

这套文档按「你可能是抱着什么疑问来的」分组。第一次用，看**上手**就够；
想搞清楚她为什么这么做，从**她怎么想**往下读。

每一条链到的都是详细说明里对应的小节。详细说明本身按主题拆成了 12 个文件，
想看某一整块（比如"事件"或"记忆"）就到[按主题拆开的详细说明](GUIDE.md)里挑。
